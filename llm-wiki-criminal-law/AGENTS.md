# AGENTS.md — 刑法阻卻違法事由入門 LLM Wiki 員工手冊

本手冊是透過「先討論、後生成」與使用者確認需求摘要後所建立的專案規範，所有 AI Agent（Antigravity / Claude Code / Codex）在操作本專案時都必須遵守。

## 1. 需求摘要（經使用者確認）
- **主題**：台灣《刑法》阻卻違法事由入門（刑法第 21～24 條與超法規阻卻違法事由）
- **目標讀者**：沒有法律背景的大學生或一般民眾（白話、生活案例導向）
- **語言**：繁體中文（台灣法律用語）
- **頁面類型**：概念條目（`wiki/concepts/`）、易混淆比較表（`wiki/comparisons/`）、總目錄（`wiki/index.md`）、操作紀錄（`wiki/log.md`）
- **出處粒度**：Wiki 條目必標 `SRC-XX` 與法條／判決字號；簡報每頁必標 `WIKI-XX` 並提供回跳連結
- **資料衝突處理**：法條原文優先於學說；若實務與學說有歧異，須同時註明並標出最高法院判決字號
- **Ingest 節奏**：逐篇 Ingest（一次 1 篇）並即時核對條號與判決
- **最終產出**：可公開瀏覽的 Wiki 網頁（`index.html`）＋ 教學型 HTML 簡報（`slides.html`）

## 2. 目錄結構與不可動限制
- `raw/`：**只讀原始資料**（`SRC-01`～`SRC-06`），不可擅自改寫或編造法條。
- `wiki/`：LLM 維護的結構化知識庫（`index.md`、`log.md`、`concepts/*.md`、`comparisons/*.md`）。
- `scripts/check_slides.js`：可執行的程式驗證腳本。
- `.agents/workflows/topic-slides.md`：從 Wiki 生成教學 HTML 簡報的 Graph Workflow。
- `report.md`：由腳本產出的最新檢查報告。

## 3. 條目模板與寫作規則
每篇 Wiki 條目（`WIKI-01`～`WIKI-06`）必須包含：
1. 識別編號（`WIKI-XX`）、對應法條、來源追溯（`SRC-XX`）
2. **一句話白話定義**（≤ 40 字，外行人一眼看懂）
3. **生活化正反案例**（成立 vs. 不成立／過當）
4. 成立要件拆解、常見誤區、與其他條目的交叉連結

## 4. 驗收與停止條件（剎車規則）
- **「做完了」不是 AI 說了算，是腳本說了算**：每次更新 Wiki 或簡報後，必須執行 `node scripts/check_slides.js` 並確認 `report.md` 全數通過。
- **獨立審查原則**：語意忠實度審查（是否講反、是否誤置三階層）須對照 `raw/` 與 `wiki/` 逐條查核，不得憑模型記憶硬湊。
- **硬上限與早停**：
  - 單一節點修正 Loop **最多 3 輪**，超過即停下交由人工處理。
  - 若檢索到的相關 Wiki 條目 **少於 3 篇**，立刻停下回報資料不足，禁止自行補編法條。
