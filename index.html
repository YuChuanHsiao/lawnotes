一篇講義，一個考點。

為準備律師、司法官與法研所考試而寫的考點講義。每篇固定依「條文 → 要件 → 實例 → 考點提醒 → 自我測驗」的順序編排，十來分鐘就能完整複習一個爭點。

每篇講義的閱讀路徑

  1. 學習目標：先知道讀完要會什麼。
  2. 條文原文與要件拆解：把條文切成可以涵攝的要件。
  3. 實例演練：先自己想，再展開「爭點 → 涵攝 → 結論」解答。
  4. 考點提醒與常見錯誤：國考會怎麼考、哪裡容易被扣分。
  5. 自我測驗：三題快速確認是否真的懂了。
